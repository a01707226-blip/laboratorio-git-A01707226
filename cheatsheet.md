git status              -   Nos dice el estado de las cosas, si hay que pullear algo, o si algo de lo que tenemos en nuestro equipo no se ha guardado.
git add                 -   Guarda los cambios en un nivel local.
git commit              -   Confirma los cambios y agrega comentarios.
git push                -   Sube los cambios a la nube.
git pull                -   Actualiza el repositorio para que esté igual que en la nube.
git log                 -   Nos dice todos los commits que se han hecho
git diff                -   Nos indica las diferencias entre el repositorio local y el guardado en la nube.
git restore             -   Nos permite restaurar un punto guardado (con un commit)
git restore --staged    -   Nos permite restaurar un punto previamente guardado sin perder cambios actuales.
